# 图片差距分析与修复策略

仅当 `iterate_mode: image` 且 `verdict: fail` 时使用。把失败收敛成**可执行的最小修复**，避免下一轮无焦点重绘。

## 分析顺序

按优先级排查，先 P0 再 P1：

1. **P0 硬伤** — `hard_fail` 与分数 ≤ 2 的维度
2. **P1 门槛分** — 仍 < 4 的维度
3. **P2 抛光** — 已 ≥ 4 但可更好的项（仅在 P0/P1 清空后考虑；未达标前不要为抛光扩大改动面）

## 问题分类 → 修复策略

| 类型 | 典型证据 | redraw_scope | 策略 |
|------|----------|--------------|------|
| 目标缺失 | 少了对象/动作/文字 | region 或 full | 在提示中点名补全；局部可补则 local |
| 目标跑偏 | 出现未要求情节 | local / region | 删除或替换跑偏元素，锁定其余 |
| 风格不符 | 线色、填色、光影语言错 | full 或 region | 重申 `target_style` 硬约束；必要时整幅按样式重套 |
| 风格混杂 | 局部像 A 局部像 B | region | 统一到目标样式，禁止再引入第三种语言 |
| 保真漂移 | 脸、服装、数量变了 | local | 强调 lock；以输入图或上轮通过区域为编辑底 |
| 质量瑕疵 | 手、文字、脏边、破形 | local | 只修瑕疵区；写清「其余像素保持」 |
| 过度修改 | 不相关区域被重画 | region | 缩小编辑范围，显式列出 preserve 清单 |

## 诊断模板字段

每条问题必须包含：

- `problem`：一句话问题
- `evidence`：画面哪里、什么现象
- `priority`：P0 / P1 / P2
- `minimum_repair`：下一轮最小动作
- `locked_invariants`：修复时不得改动的项

整轮诊断还要给出：

- `preserve_next`：下一轮保持清单
- `redraw_scope`：`local` | `region` | `full`

## 范围选择规则

- 默认 `local`：单点瑕疵、小物体、局部风格脏色
- 用 `region`：同一语义区多项问题（如整个人物上半身、整块背景墙）
- 仅当风格整体错、构图骨架错、或局部修连续失败 ≥ 2 轮时升为 `full`
- 升级到 `full` 时，仍须在提示中带回 `lock` 与已通过的内容约束

## 防振荡

- 同一问题连续两轮无改进 → 更换策略（改 scope、改参考图用法、或拆成更小修复点），不要重复同一句空泛提示
- 禁止为修 A 而引入新的 B；若引入新 hard_fail，下一轮先回滚该回归再继续
- 已 ≥ 4 的维度：非必要不主动改；在 Plan 里写明「保持」

## 与画风 skill 协作

若用户指定了 `style_skill`：

1. 诊断中的风格问题，优先引用该 skill 的验收失败项原文
2. Produce 阶段按该 skill 的提示词 / 参考图协议执行
3. 本文件只决定「修什么、修多大」，不覆盖画风细节
