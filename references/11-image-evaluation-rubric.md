# 评测量表（图片模式）

仅当 `iterate_mode: image` 时使用。先按 [02-round-protocol.md](02-round-protocol.md) 完成 **Expected vs Actual**（对照 Brief 的 `expected_checklist`），再打分。必须先看全图，再对可疑区域放大检查。

打分锚点：`source_image`、`goal`、`target_style`、`lock`、`acceptance`、清单逐条状态。

## 四维分数（各 0–5）

### score_goal — 目标达成

| 分 | 含义 |
|----|------|
| 5 | 目标要求全部可见落实 |
| 4 | 主目标达成，仅有轻微次要遗漏 |
| 3 | 主目标部分达成，关键要求缺失或跑偏 |
| 2 | 仅沾边，主体意图未完成 |
| 0–1 | 与目标无关或严重相反 |

### score_style — 样式匹配

| 分 | 含义 |
|----|------|
| 5 | 线质、填色、光影、色彩语言与 `target_style` 一致 |
| 4 | 整体对，有 1 处可辨风格偏差 |
| 3 | 能看出意图，但风格混杂或不稳定 |
| 2 | 明显不像目标样式 |
| 0–1 | 完全偏离 |

若绑定了画风 skill，以该 skill 的验收项为 `score_style` 的细则来源。

### score_fidelity — 应保留内容的保真

| 分 | 含义 |
|----|------|
| 5 | `lock` 与未要求修改的主体、数量、文字、身份均稳定 |
| 4 | 保真良好，仅有不影响识别的细微漂移 |
| 3 | 出现可察觉的身份/数量/构图漂移 |
| 2 | 关键锁定项被改掉 |
| 0–1 | 几乎重画成另一套内容 |

无 `lock` 时：仍须保留用户未要求改变的主体身份与关键对象，除非 `goal` 明确要求替换。

### score_quality — 画面质量与可用性

| 分 | 含义 |
|----|------|
| 5 | 无影响交付的缺陷 |
| 4 | 有轻微瑕疵但不影响使用 |
| 3 | 有明显瑕疵（糊、脏边、肢体错误、文字乱码等） |
| 2 | 多处质量问题 |
| 0–1 | 不可用 |

## 硬伤 hard_fail（任一即 fail）

- 清单中硬性项 `unmet`（数量、对象、动作、指定文字等）
- 明确违反 `target_style` 硬约束（如要纯黑细线却彩线；要双色却多色渐变）
- 破坏 `lock` 或上轮已 met 项出现回归
- 严重解剖/透视/遮挡错误导致主体不可用
- 文字需求下出现不可读乱码
- 用户 `acceptance` 任一条未满足

## 达标判定

```
pass  ⟺  hard_fail 为空
      ∧  清单硬性项全部 met
      ∧  score_goal ≥ 4
      ∧  score_style ≥ 4
      ∧  score_fidelity ≥ 4
      ∧  score_quality ≥ 4
      ∧  （若有 acceptance，则全部满足）
```

否则 `fail`。同步更新 `best_so_far`（见 02）。

## 评测写法要求

- 先表后分：无 Expected vs Actual 表不得给 verdict
- 低于 5 分的维度至少一条可见证据（位置 + 现象）
- `hard_fail` / `actual` 可复核，禁止「不太好」
- 各轮同一量表，便于看是否进步
