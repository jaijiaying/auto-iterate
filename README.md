# auto-iterate

按“产出 → 实际验证 → 对照目标评测 → 诊断再改”迭代交付物，直到达标或达到轮次上限。执行规范见 `SKILL.md`。

支持五种迭代对象：

| 模式 | 可迭代内容 |
|---|---|
| 图片 | 插画、照片、视觉素材 |
| Skill | `SKILL.md`、references 与相关资源 |
| 功能 | 可运行的软件功能、交互和端到端行为，可跨多个文件 |
| 指标优化 | 已有系统或流程的性能、稳定性、成本、准确率、可用性等 |
| 通用交付物 | 文档、代码、提示词、表格、演示稿、网页、设计文件等 |

每轮用同一份可观察的验收清单检查真实产物，记录验证证据，并对已经达标的条件做回归检查。连续无进展时调整诊断或方法；保存可恢复的历史最佳版本。默认最多 5 轮；未达标时交付历史最佳版本和剩余问题。具体制作和验证依赖对象对应的工具或专用 skill。

本 skill 配置为显式调用（`disable-model-invocation: true`）。
